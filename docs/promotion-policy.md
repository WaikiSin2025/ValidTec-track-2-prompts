# Promotion and Rollback Policy

A candidate prompt/context package is eligible for promotion only when:

- quality does not fall below the approved baseline;
- total evaluation pass rate is at least 95%;
- no critical evaluation case fails;
- estimated token usage does not increase; and
- estimated token usage improves by at least 15% in this demonstration.

Human review remains required before treating a candidate as production-approved. The automated gate supplies evidence; it does not replace accountable approval.
